# HCI — Ciencia Cognitiva

## Resumen

Estudio de la mente y sus procesos: lenguaje, percepción, memoria, atención, razonamiento, emoción.  
En HCI: la computación modela el pensamiento → el diseño debe adaptarse a los límites cognitivos humanos.

### Carga Cognitiva
Como una computadora, el cerebro tiene un límite de procesamiento. Superarlo genera estrés y errores.

**Tipos:**
- **Intrínseca**: esfuerzo necesario para entender la tarea. Reducir distracciones visuales, autocompletar entradas frecuentes, mantener el diseño simple.

**Reglas de diseño:** eliminar lo que distrae, autocompletar campos frecuentes, diseño mínimo.

### Atención Selectiva
El usuario se enfoca en la tarea; elementos visuales compiten por su atención.

**Peso visual** (qué llama más la atención):
- Tamaño
- Forma (circular > estrella)
- Color (brillo y saturación)
- Contraste

**Visión de túnel**: al concentrarse, se pierde la visión periférica.

### Memoria
- **Número mágico 7**: las personas retienen aprox. 7 ítems en memoria de trabajo.
- Diseñar para minimizar lo que el usuario debe memorizar.

### Percepción Visual — Teoría de Gestalt
El cerebro busca completar figuras y organizar estímulos en grupos coherentes.

**Principios de Gestalt:**
| Principio | Descripción |
|---|---|
| Similitud | Elementos parecidos se perciben como relacionados |
| Proximidad | Elementos cercanos se perciben como un grupo (> similitud) |
| Cierre | El cerebro completa figuras incompletas |
| Conectividad | Elementos conectados se perciben como grupo |
| Destino común | Elementos sincronizados se perciben como grupo |
| Continuidad | El ojo sigue rutas/líneas |
| Figura y fondo | Se diferencia el objeto de lo que lo rodea |

Los principios pueden superponerse; aplica el de mayor peso perceptual.

### Ley de Fitts
Los **movimientos rápidos** hacia **objetivos pequeños** producen **más errores**.  
→ Los elementos interactivos frecuentes deben ser grandes y estar cerca.

### Ley de Hick
Cuantas más opciones, más tiempo tarda el usuario en decidir (relación logarítmica).  
→ Simplificar menús; presentar pocas opciones a la vez.

### Emociones y Diseño
Las emociones forman parte de la toma de decisiones.

| Nivel | Descripción |
|---|---|
| **Visceral** | Reacciones automáticas, involuntarias |
| **Conductual** | Basadas en experiencias aprendidas |
| **Reflexivo** | Consciente, racional |

## Notas
- Frases largas aumentan la carga cognitiva → prefiere texto conciso.
- Los fondos difuminados, el tamaño y el contraste ayudan a separar figura de fondo.
- Diseñar con buena experiencia para usuarios nuevos, frecuentes y esporádicos por igual.
