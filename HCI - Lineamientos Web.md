# HCI — Lineamientos de Usabilidad para Sitios Web

## Resumen

### Principio Central
**Hacer pensar lo menos posible al usuario.** Cada elemento que requiere interpretación añade carga cognitiva innecesaria.

### Cómo Usan los Usuarios los Sitios Web
- Los usuarios **no leen**, **escanean**. Buscan lo que les resulta relevante.
- Siguen patrones conocidos (convenciones web).
- Se basan en su **modelo mental** para navegar: buscan donde esperan encontrar las cosas.
- Si algo no funciona rápido, van al próximo enlace (paciencia baja).

### Diseño de Páginas
1. **Diseño mínimo**: solo incluir lo que aporta valor.
2. **Usar convenciones**: elementos familiares reducen la curva de aprendizaje.
3. **Jerarquía visual clara**: el elemento más importante debe tener mayor peso visual.
4. **Texto escaneable**: títulos, bullets, texto corto; evitar párrafos largos.
5. **Consistencia**: mismo elemento = mismo comportamiento en todo el sitio.

### Diseño de Navegación
- Los usuarios navegan según su modelo mental: colocar la información donde ellos esperan encontrarla.
- **Navegación persistente**: los elementos de navegación deben aparecer en todas las páginas.
- Siempre indicar dónde está el usuario (breadcrumbs, menú activo).
- El logo de la empresa debe llevar a la página de inicio.

### Anti-patrones (cosas que hacen pensar)
- Nombres de links/botones no claros.
- Elementos interactivos no reconocibles como tales.
- Falta de feedback tras una acción.
- Texto sin jerarquía visible.
- Demasiadas opciones al mismo nivel (Ley de Hick).

## Notas
- El usuario escanea en patrones F o Z; el contenido crítico debe estar en esas zonas.
- La usabilidad móvil añade restricciones extra: targets grandes (Ley de Fitts), menos opciones visibles.
