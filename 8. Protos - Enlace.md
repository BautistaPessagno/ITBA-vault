TDMA (Time Division Multiple Access)
- Cada tributario, o nodo tiene asignado un time-slot use o no lo use.
- Ejemplo: PDH agrupa 30+2 canales de 64Kb/s para obtener 2048 kbit/s (E1)

FDMA (Frequency Division Multiple Access)
-  Cada tributario, o nodo tiene asignado una frecuencia use o no lo use.
- Ejemplo: Radio FM.

CDMA (Code Division Multiple Access)
- Cada nodo tiene un Código pseudo-aleatorio que tiene la característica de ser ortogonal con otros códigos
- Ejemplo: Tecnologías de comunicaciones cellular anteriores al 3G.

## Token Ring
![[Pasted image 20260430203211.png]]

- Fue desarrollado originalmente por IBM en los años 1970 y se convirtió en un estándar bajo la norma IEEE 802.5
- Conjunto de nodos conectados en forma de anillo
- Los datos circulan en un único sentido
- Cada nodo recibe un «token» que lo habilita a transmitir
- El anillo es compartido pero sólo transmite el que recibió el «token» durante cierto tiempo
