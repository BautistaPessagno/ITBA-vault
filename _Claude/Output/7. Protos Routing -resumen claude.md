# Resumen Clase 06 - Routing

Resumen orientado a resolver la **Guía 06 de ejercicios**.

---

## 1. Clasificación de tipos de ruteo

### Ruteo mínimo
Una red aislada de otras redes TCP/IP. No necesita protocolo de routing.

### Ruteo estático
La tabla de ruteo es construida por un **administrador** en forma manual. Adecuado para redes pequeñas y estables.

### Ruteo dinámico
La tabla de ruteo se construye automáticamente en base a información intercambiada por **protocolos de routing**. Se adapta a cambios de topología.

---

## 2. Clasificación de algoritmos dinámicos

| Característica | Descentralizado (Distance Vector) | Global (Link State) |
|---|---|---|
| Conocimiento | Solo vecinos | Toda la red |
| Intercambio | Tabla de ruteo con vecinos | Estado de enlaces con todos |
| Algoritmo | Bellman-Ford | Dijkstra |
| Ejemplo | RIP | OSPF, IS-IS |

---

## 3. Distance Vector Algorithm

Cada router recibe de sus **vecinos** una tabla de enrutamiento. En base a ella actualiza su propia tabla y la envía a sus vecinos.

### Funcionamiento paso a paso

1. Cada router conoce inicialmente solo la distancia a sus vecinos directos
2. Recibe tablas de sus vecinos
3. Actualiza sus distancias: `D(X,Y) = min(costo(X,vecino) + D(vecino,Y))` para cada vecino
4. Envía su tabla actualizada a los vecinos
5. Se repite hasta **convergencia** (las tablas no cambian más)

### Convergencia
- **Buenas noticias viajan rápido**: si un nodo se activa, la información converge en pocos intercambios
- **Malas noticias viajan lento**: si un nodo pierde conectividad, los routers se actualizan mutuamente con información obsoleta

---

## 4. Problema de contar hasta infinito

Si un enlace se cae, los routers vecinos pueden entrar en un ciclo donde incrementan las distancias de a uno hasta llegar a infinito.

```
Ejemplo: A pierde conexión con B

Intercambio  B    C    D    E
    0        ∞    2    3    4
    1        3    2    3    4
    2        3    4    3    4
    3        5    4    5    4
    ...      ...  ...  ...  ...
```

El problema ocurre porque C le dice a B "yo llego a A por 2" (pero la ruta de C pasa por B).

### Soluciones

- **Split Horizon**: no enviarle a un vecino lo que ese vecino te informó
- **Ruta envenenada (Poisoned Reverse)**: lo que el vecino te envía, se lo devolvés con distancia ∞
- **Envío rápido de malas noticias**: si se detecta un problema en un vínculo, enviar inmediatamente esa entrada "envenenada"

## 5. Sistemas Autónomos (AS)

Un **sistema autónomo** es un conjunto de redes bajo una misma administración o política de routing común.

| Tipo | Sigla | Uso | Ejemplo |
|---|---|---|---|
| Interior Gateway Protocol | IGP | Dentro del AS | RIP, OSPF, IS-IS |
| Exterior Gateway Protocol | EGP | Entre ASs | BGP |

## 6. RIP - Routing Information Protocol

### RIP v1 (RFC 1058, 1988)

- Algoritmo **Distance Vector**
- Métrica: **cantidad de saltos** (hop count)
- Máximo **15 saltos** (16 = inalcanzable)
- Intercambia información cada **30 segundos**
- Paquetes enviados por **broadcast**
- Usa notación **classfull** (no informa máscara de subred)
- **Sin autenticación**

> [!important]
> Al usar classfull, si A tiene `10.1.0.0/16` y C tiene `10.4.1.32/27`, ambos informan a B la red `10.0.0.0/8`, perdiendo información de subredes.

### RIP v2 (RFC 2453, 1998)

- Informa direcciones **CIDR** (con máscara)
- Updates por **multicast** (no broadcast)
- **Autenticación opcional** (texto plano o MD5)
- Compatible con RIP v1

### Formato de paquete RIP v2

```
| Command (1B) | Version=2 (1B) | Reserved (2B) |
| Address Family = 2 (IPv4)     | Route tag      |
| IP address (4B)                                |
| Subnet mask (4B)                               |
| Next hop (4B)                                  |
| Metric (4B)                                    |
```

- Command: 1 = Request, 2 = Response
- Hasta **25 entradas** por paquete

### Con autenticación
La primera entrada usa `Address Family = 0xFFFF` y contiene los 16 bytes de autenticación.

### Demonio routed (Unix)

```bash
# No necesita parámetros ni archivos de configuración
# Opcionalmente: /etc/gateways
net 192.160.14.0 gateway 172.14.88.12 metric 1 passive
```

## 7. Link State Algorithm

Cada router recibe del **resto de los routers** información sobre sus vecinos. Con ella arma un **grafo completo** de la red y calcula los caminos más cortos.

### Pasos

1. **Descubrir** a los vecinos
2. **Medir** la distancia (demora o costo) a cada vecino
3. **Construir** un paquete LSA (Link State Advertisement) con lo aprendido
4. **Enviar** el paquete a **todos** los routers de la red (flooding)
5. **Calcular** el camino más corto a cada router usando **Dijkstra**

## 8. OSPF - Open Shortest Path First (RFC 2328, 1998)

- Algoritmo **Link State**
- Modelo **jerárquico** con áreas
- Envía información solo **cuando se detecta un cambio** en la topología (no periódicamente)
- Permite asignar **peso/costo** a los enlaces
- Cada router construye un grafo y usa **Dijkstra**
- **Sin límite** de diámetro de red

### Áreas

- **Área 0 (backbone)**: todas las áreas deben conectarse a ella
- **ABR (Area Border Router)**: router de borde que conecta un área con el backbone
- Los ABR **sumarizan** las redes de un área, reduciendo las tablas de ruteo
- **Área stub**: no requiere ABR de gran capacidad, usa ruta por defecto y tabla estática

## 9. Protocolos de ruteo en la pila TCP/IP

```
Aplicación:  FTP, HTTP, TELNET, TFTP, DNS
Transporte:  TCP, UDP
Red:         IP, ICMP, IGMP
Routing:     RIP, OSPF, IS-IS, BGP, EIGRP, PIM
Enlace:      ARP, Ethernet
```

> [!note]
> RIP usa **UDP** (puerto 520), mientras que OSPF se encapsula directamente en **IP** (protocolo 89). BGP usa **TCP** (puerto 179).

## 10. Tabla comparativa: Distance Vector vs Link State

| Aspecto | Distance Vector | Link State |
|---|---|---|
| Visión de la red | Solo vecinos | Topología completa |
| Cálculo de ruta | Suma distancias de router a router | Camino más corto (Dijkstra) |
| Actualizaciones | Frecuentes y periódicas | Solo por cambios de topología |
| Envío de info | Copia de tabla a vecinos | Estado de enlace a todos los routers |
| Diámetro de red | Limitado (15 saltos en RIP) | Sin límite |
| Convergencia | Lenta | Rápida |
| Complejidad | Simple | Mayor |

---

## 11. Criterios para elegir protocolo

| Escenario | Recomendación |
|---|---|
| Red pequeña, simple | RIP v2 o ruteo estático |
| Red empresarial con subredes | OSPF |
| Red en constante crecimiento | OSPF (se adapta mejor a cambios) |
| Comunicación entre ISPs | BGP |
| Red con subredes de tamaño variable | RIP v2 u OSPF (necesitan CIDR) |
