# 9. Protos - SSH

![](Attachments/Pasted%20image%2020260507144936.png)
para poder operar remotamente una computadora se usaba telnet pero no era seguro
SSH es un remplazo seguro para telnet
SSH ofrece autenticación de los dos lados
![](Attachments/Pasted%20image%2020260507145356.png)
tambien encriptacion
![](Attachments/Pasted%20image%2020260507145509.png)

![](Attachments/Pasted%20image%2020260507150612.png)
