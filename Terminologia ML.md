# Terminologia
 - **Classifier / Model:** El componente que aprende la regla de decisión y produce la predicción. / The component that learns the decision rule and produces the prediction. 
	 - Ej.: Decision Tree, SVM, Logistic Regression, Random Forest.
	 - 
-  ML Pipeline: El sistema completo desde las features de entrada hasta la predicción. / The complete system from input eatures to prediction.
	X→preprocessing→feature selection→classifier→y

- **Parameters**: Valores aprendidos durante el entrenamiento. / Values learned during training.
- **Hyperparameters**: Decisiones que configuran el aprendizaje o el pipeline. / Choices that configure the learning process or the pipeline. 
	- Ej.: max_depth, C, k en feature selection.
- **Feature set:** Conjunto de variables que decidimos usar. / The set of features we decide to use.
