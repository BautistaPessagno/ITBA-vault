# POO - Documentación

Links de referencia oficial y de apoyo para los dos lenguajes que cubre la materia.

## Documentación Java

- [Java SE 21 API Docs](https://docs.oracle.com/en/java/javase/21/docs/api/) — JavaDoc oficial de la API estándar (paquetes, clases, interfaces).
- [roadmap.sh/java](https://roadmap.sh/java) — roadmap de aprendizaje de Java; útil para ubicar un tema dentro del panorama general del lenguaje.

## Documentación Ruby

- [Ruby Essentials (Techotopia)](https://www.techotopia.com/index.php/Ruby_Essentials) — guía introductoria a Ruby, orientada a quien ya sabe programar en otro lenguaje.
- [Ruby 3.2 Documentation](https://docs.ruby-lang.org/en/3.2/index.html) — documentación oficial del lenguaje y su standard library.
