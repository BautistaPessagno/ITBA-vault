# Asignación de direcciones IP
para poder estar en una red a un host hay que asignarle una dirección IP

![](Attachments/Pasted%20image%2020260421080852.png)
### Direccionamiento estático
a cada host le seteo cual va a ser su numero de IP
es recomendable para casos con especificos con poco movimiento y hosts fijos

### Direccionamiento dinamico
uno en su casa no esta cambiando la IP cada vez
lo mas comun
- RARP
- BOOTP
- DHCP

### BOOTP

### DHCP ( Dynamic HOst Configuration Protocol)
protocolo de aplicacion
- el cliente puede conocer o no la direccion IP del servidor DHCP -> es decir manda un broadcast
- la asignacion IP es dinamica pero permite reservar direcciones IP para direcciones MAC
![](Attachments/Pasted%20image%2020260421081804.png)

al ser un protocolo de aplicación se necesita un protocolo de Transporte
Tiene un discovery para obtener una IP
como para TCP necesitas la IP origen y destino => es sobre UDP


![](Attachments/Pasted%20image%2020260421082052.png)
